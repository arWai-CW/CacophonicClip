Cacophonic Clip 安裝說明（macOS）

1. 安裝

   對「安裝 Cacophonic Clip.app」按右鍵 → 打開 → 打開。

   跳「無法驗證開發者」是正常的，這個外掛沒有 Apple 開發者簽章。

   右鍵沒有「打開」時，改按兩下，然後到
   系統設定 → 隱私權與安全性 → 捲到最下面 → 按「仍要打開」。

2. 打開 DAW

   安裝完請完全關閉再開你的 DAW（Cmd+Q），讓它重新掃描外掛。


要自己拖的話

   ~/Library/Audio/Plug-Ins/VST3/Cacophonic Clip.vst3
   ~/Library/Audio/Plug-Ins/Components/Cacophonic Clip.component
